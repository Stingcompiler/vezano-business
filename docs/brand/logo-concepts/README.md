# أفكار شعار «فيزانو بلص»

أفكار أولية للشعار. المطلوب منه أن يجمع وظيفة النظام وهويته، إذ رأى المالك (2026-09-26) أن علامة الأعمدة الحالية لا تعكس أهداف الموقع. هذه مسودات للفكرة لا تصميم نهائي؛ للافتات والمطبوعات يصقلها مصمّم ابتداءً من هذه الملفات.

**ما يجب أن يحمله الشعار**
- **الوظيفة**: دفتر البيع والذمم والمخزون.
- **الوعد**: يعمل بلا شبكة ويتزامن، ويصل المحل بمورديه.
- **الهوية**: عربية سودانية.

## لماذا المزيج
- **الحرف**: «ف» أول حرف من الاسم، فيحمل الهوية. الحرف الواحد يبقى واضحاً في أيقونة الهاتف وتبويب المتصفح (16 بكسل).
- **المظلّة**: تقول «محل» لمن لا يقرأ، ويكفيها أربعة أقواس فلا تضيع عند التصغير.
- **سطرا الدفتر**: جوهر النظام، البيع والذمم.
- **النقطة الذهبية**: هي نقطة «ف» نفسها، وتعني الاتصال (المزامنة والسوق). يمكن أن تتكرر في الواجهة لوناً لحالة المزامنة وشارة السوق.
