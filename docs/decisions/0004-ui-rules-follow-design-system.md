# 0004 — حسم س١ وس٢ وس٩: نظام التصميم هو الحاكم

**التاريخ:** 2026-09-15 · **الحالة:** معتمد — قرار صاحب المشروع («اتبع توصيات نظام التصميم»)
**المرجع:** `docs/decisions/0002` س١ وس٢ وس٩؛ `02-Design-System.dc.html` §٢ و§٤ و§٥

| السؤال | القرار | ما يتغير |
|---|---|---|
| س١ حلقة التركيز | **accent `#F59E0B` بسمك 3px وإزاحة 2px** ولا تُزال أبداً (DS «التركيز مرئي دائماً») | `23-Handoff` كان يقول 2px teal-700؛ يُعامل قديماً |
| س٢ ارتفاع C-BTN | **44px حدّاً أدنى على كل المنصات**، **56px** للفعل المالي الأساسي على الهاتف، **46px** على تابلت POS (`W/834`، S-01) | المقاسات 32/40/48 في `23-Handoff` تُلغى؛ الكثافة تُعالج بحشو الخلية لا بتصغير الزر |
| س٩ مقاس 15px | **15px / 400 هو نص الواجهة الأساسي** على كل المنصات؛ **14px / 400** صفوف الجداول والكشوف | `tokens.json`: يُضاف `fontSize.base` (15px، وزن 400) ويُصحَّح وصف `subTitle` بأن 15/600 «عنوان فرعي» للتسميات القصيرة فقط؛ الوصف في README يُعامل قديماً |

## ما يترتب على المكوّنات (T0.14 فصاعداً)

- كل عنصر تفاعلي: `min-block-size: 44px` و`min-inline-size: 44px`؛ الزر المالي الأساسي `data-financial` على 390 يرتفع إلى 56px.
- حلقة التركيز عبر `:focus-visible` بـ`outline: 3px solid var(--color-accent); outline-offset: 2px` — لا `outline: none` في أي مكان.
- النص الأساسي `font-size: var(--text-base)` (15px) بوزن 400؛ الجداول `--text-body` (14px).

## ما لم يُحسم بعد

س٤ (ترقيم G-17 وتشفير النسخة) قبل T1.37، وإذن تنزيل ملفات الخطوط.
